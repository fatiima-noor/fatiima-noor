### hey, I'm Fatima 👋

I build things that actually hold up under pressure — full-stack, AI-heavy, and hackathon-tested.

I'm a Software Engineering student at PUCIT (graduating **May 2026**), and for the past four years I've been shipping products end to end: Django and FastAPI backends, React frontends, LLM integrations, RAG pipelines. My final year project, **StudyMate**, is an AI-powered study platform with RAG-based document ingestion, real-time chat, adaptive quizzes, and semantic search — I led the backend architecture and LLM integration.

I've also won **5 hackathons**. Mostly that means I'm good at making calls at 3am when everything is on fire.
